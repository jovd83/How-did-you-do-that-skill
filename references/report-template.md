# Report template

Produce **one** Markdown file with these two halves. The narrative is for a colleague who
wasn't there; the appendix is for someone who wants to verify or reproduce. Fill every
`{placeholder}` from evidence — JSON for numbers, transcripts for story. Drop any row that
genuinely doesn't apply rather than writing "N/A" everywhere.

## Style reminders

- **Convert units.** Raw seconds and bare token counts are unreadable. "≈3.2 h" and
  "1.1 M output tokens" beat "11536 s" and "1144941".
- **Don't average across models.** Show the split; it's usually meaningful.
- **Cached-read tokens dominate and are cheap.** Always separate them so the cost story
  isn't distorted.
- **The appendix verifies the narrative.** Every claim in the story should be checkable
  against a number in the appendix.
